# Tema WordPress "Tediado Clone"

Tema criado com base na estrutura observada em **www.tediado.com.br**.

## O que já vem pronto

- Cabeçalho com marca + menu de categorias.
- Página inicial em formato de cards de posts.
- Sidebar com blocos de categorias e conteúdos em destaque.
- Template de post individual.
- Templates de **arquivo**, **busca** e **erro 404**.
- Rodapé simples no estilo editorial/blog.
- Personalização de cor principal via **Aparência > Personalizar**.

## Instalação

1. Copie a pasta `wordpress-theme-tediado` para `wp-content/themes/tediado-clone`.
2. No painel WordPress, ative o tema **Tediado Clone**.
3. Crie e atribua um menu à posição **Menu Principal**.
4. (Opcional) Adicione widgets na **Sidebar Principal**.
5. (Opcional) Ajuste a cor principal em **Aparência > Personalizar > Tediado Clone: Cores**.

## Observação

Este tema é uma **inspiração visual/estrutural**. Para ficar 100% igual ao site de referência, pode ser necessário incluir anúncios, plugins e widgets específicos do projeto final.
